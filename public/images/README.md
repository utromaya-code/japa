# Фото для лендинга

## Леонид Кутузов (блок «О Леониде»)

Положите сюда фото Леонида и назовите файл:

**`leonid-kutuzov.jpg`**

(или `leonid-kutuzov.png` — тогда в `AboutInstructor.tsx` замените расширение на `.png`)

Если у вас файл называется «LEO - Xenia Barbur 2024-08-09.jpg», переименуйте его в `leonid-kutuzov.jpg` и скопируйте в эту папку.

После этого на сайте в блоке «О Леониде Кутузове» будет отображаться ваше фото. Если файла нет, показывается заглушка.
