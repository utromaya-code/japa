# Фото для галереи (в т.ч. Хоккайдо)

Сюда можно добавлять новые фотографии для блока «Галерея» на лендинге.

## Рекомендации

- **Формат:** JPG или WebP
- **Размер:** до 1920×1080 px (Full HD)
- **Вес:** 200–500 KB на фото (оптимизируйте в [Squoosh](https://squoosh.app/) или [TinyPNG](https://tinypng.com/))

## Имена файлов для Хоккайдо

- `hokkaido-1.jpg`, `hokkaido-2.jpg` — горы Хидака, природа
- `lake-toya-1.jpg` — озеро Тойя и гора Ётэй
- `otaru-canal-1.jpg` — канал Отару вечером
- `mount-usu-1.jpg` — вулкан Усудзан
- `jigokudani-1.jpg` — Дзигокудани (Адская долина, Ноборибецу)

После добавления файлов нужно прописать их в **`src/data/gallery.ts`**: добавить объект с полями `src`, `alt`, `title`, `category: 'hokkaido'`. Путь к файлу: `images/gallery/имя-файла.jpg`.
